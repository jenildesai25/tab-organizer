# A rule is compiled once, when it is saved

A rule is a plain sentence that renames a site's group or places several sites under one title. The sentence is compiled once, at save time, into a list of sites and a title, and that compiled meaning is shown back before it takes effect.

Leaving the sentence as text and asking a model what it means on every tab would make filing wait on the model, would let the same sentence change meaning between tabs, and would make a saved rule stop working with the LLM switch off.
